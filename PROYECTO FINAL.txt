Fase 0: Modelo de dominio para Intranet Académica
- ARQUITECTURA
	Frontend Web  -> React + Vite
	Backend API   -> NestJS
	Base de datos -> MySQL + Prisma
	Futuro móvil  -> React Native consumiendo la misma API
- API REST
	/api/v1/auth/login
	/api/v1/users
	/api/v1/academic/sedes
	/api/v1/academic/salones
	/api/v1/academic/secciones
	/api/v1/academic/cursos
- FLUJO
	Web App      ----\
 	                 |---> API NestJS ---> MySQL
	Mobile App   ----/

- ENTIDADES DEL SISTEMA
	Sede
	Usuario
	Perfil de usuario
	Rol / Membresía de rol
	Período académico
	Turno
	Salón
	Sección
	Curso
	Sección-Curso
	Matrícula de estudiante
	Asignación docente
	Relación padre-estudiante

- DIAGRAMA CONCEPTUAL
	Sede
		├── Usuarios / Membresías
		├── Salones
		├── Períodos académicos
		└── Turnos

	Salón
		└── Secciones

	Sección
		├── Estudiantes matriculados
		└── Sección-Cursos

	Curso
		└── Sección-Cursos

	Sección-Curso
		└── Docente asignado

	Usuario
		├── Puede tener múltiples roles
		├── Puede estar en múltiples sedes
		├── Puede ser estudiante
		├── Puede ser docente
		└── Puede ser padre de familia

	Padre de familia
		└── Está vinculado a uno o varios estudiantes
